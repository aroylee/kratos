Kratos Architecture

Sovereign multi-engine conversational data intelligence & governance framework

Contract-Driven Pipeline

  • • InterpretedRequest → DataTask → DataEvidence → FinalAnswer
  • • Pydantic-inmutable: sin bucles de chat libres entre agentes
  • • Orquestación determinista Agent A → Agent B
  • • Harness con audit_components() y benchmarks integrados

Defense in Depth (SQL)

  • • 4 capas AST con sqlglot: mutations, CTE exploits, system tables, complejidad
  • • Solo SELECT / WITH…SELECT — nada de DDL/DML
  • • LIMIT 500 forzado en runtime
  • • SQLite abierto con uri mode=ro (read-only real)

Semantic BI Integrity

  • • Multi-engine in-process: DuckDB + SQLite con auto-discovery
  • • Unidades estrictas ($ USD, %, días, pedidos, unidades)
  • • No-aditividad y escala formateadas, anti-alucinación
  • • LLM agnóstico vía litellm (modelos locales incluidos)
